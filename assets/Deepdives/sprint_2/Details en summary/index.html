States van details

Waar is de default state voor?

Een button wordt in de default state getoond als er niet mee geïnteracteerd wordt, en als hij niet disabled is.

Waar is de focus state voor?

Als een button de focus state heeft, dan betekent dat dat de gebruiker er mee kan interacteren. Hoe dat precies kan is afhankelijk van het apparaat. Dat kan bijvoorbeeld met de spatiebalk of de enter toets met het toetsenbord, door de klikken met de muis, of door met een andere controller te klikken.

Waar is de hover state voor?

De hover state wordt getoond als de gebruiker met een muis (of een ander pointer device) over de button hovert.

Waar is de active state voor?

Zodra de button wordt ingedrukt dan wordt de active state getoond. Dat is vaak maar héél kort.
